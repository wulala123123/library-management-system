# 旧上传文件迁移参考

这里保留原来由 Git 跟踪的 3 张历史头像，路径和字节均保持不变。它们属于旧运行上传数据，源码和 SQL 种子没有引用，不能据此认定为新库演示素材。文件校验见 `SHA256SUMS`。

原本机 `backend/uploads/` 中的文件仍在，仅停止 Git 跟踪。新的上传文件继续进入忽略的运行目录或持久化卷；归档不随发布 ZIP 分发，也不在启动时自动导入。

接管旧库时先备份真实上传目录。核对 `sys_user.avatar` 保存的相对路径，如果引用这些历史头像且原上传目录缺文件，可以将本目录 `uploads/` 下对应文件按原相对路径补入上传卷。真实旧上传目录优先，不以这 3 张参考文件代替完整文件备份。
