# 图书馆管理系统修复版

关闭未接入真实短信的匿名密码重置；登录在后端消费验证码；已有管理员密码保留，敏感账号操作撤销旧令牌。统一数据库迁移，修复逾期保护、并发借还、借阅码重复借阅和已有 ISBN 采购入库。前端构建包含完整 Vue 类型检查。

目录只生成借阅码，核销时创建借阅并扣库存。生成码不预留库存。首次管理员凭据必须自行配置，没有生产默认密码。

发布包支持独立数据和上传卷、健康检查、更新备份及隔离恢复。部署前阅读 `docs/deployment.md`、`docs/database-migrations.md` 和验收记录；旧库不得删除重建。发布流程必须先通过 Verify，已有 Release 或标签不会被删除。
