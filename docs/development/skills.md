# 项目技能

项目自带技能保存在仓库根目录 `.agents/skills/`，与仓库一起维护。通用流程、模板和项目适配按需读取，固定项目入口继续承担各自职责。

## 项目经理

入口：[$codex-project-manager](../../.agents/skills/codex-project-manager/SKILL.md)。适用于项目统筹、有边界的任务委派、多会话协作及交付验收；普通独立修复直接处理。

核心流程为派发任务、等待交付、经理验收、必要返工、更新项目状态。经理复用 PROJECT、PLAN 和阶段文件，员工只负责指定范围。同一可写任务只有一个执行者，经理在授权范围内完成本批闭环。

本地技能沿用用户指定的 QuantProject 版本，通用模板与会话适配保留，项目专用说明改为[图书馆接入](../../.agents/skills/codex-project-manager/references/library-project.md)。本项目独立维护该副本；后续同步源技能时先核对差异，保留本地适配。

模型及思考强度的默认值由技能入口统一维护。用户明确配置优先，技能文字本身不会切换当前会话模型；派发时只在支持的工具参数中应用并核对，无法核实的配置明确说明。

## 使用与维护

- 可以明确使用 `$codex-project-manager` 管理指定目标，或在适用统筹任务中按 AGENTS 使用。导入或修改技能本身不启动会员业务任务。
- 当前任务内实施子任务按技能会话适配处理；新建独立员工会话、联系其他会话及后台调度仍按对应授权执行。
- 技能只路由项目规则，不重复定义业务契约、阶段验收和部署权限。原始日志及真实资料继续放受保护的私有位置。
- 新增技能建立独立主题目录，在本页登记入口。修改后运行技能校验并检查所有本地资源链接，再运行项目文档检查。

项目文档检查同时验证技能的本地资源链接，分发包收集项目技能及其支持资源，使文档中的技能入口可在解压包内继续使用。

项目目录技能的发现机制见[官方 OpenAI 文档](https://developers.openai.com/codex/skills/)。当前会话可直接按已读取技能工作；技能选择器是否已刷新以实际界面为准。
