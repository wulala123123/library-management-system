# 数据承接与修正

## 适用范围

处理源系统导出的图书、实体册、会员、借还历史、套餐和订单资料。字段语义见[领域规范](../specs/README.md)，本页维护导入和修正操作边界。

## 来源及映射

- 官方导出与必要页面详情交叉核对，保存来源清单及 SHA256。原文件、真实快照和密码散列保留在私有目录。
- 书目按核对过的 ISBN 或源标识归类，实体册保留唯一馆内条码；在借记录关联实际册及会员。
- 会员按来源 UID 建立身份，共享手机号保留独立会员。原账号密码不具备直接迁移条件。
- 原服务起止日、实际费用、押金及状态按来源保存。不限次数使用明确不限；原文本映射错误的定向修正已完成，后续不得重跑该批导入。
- 历史不限期和来源未提供的应还日期分别标记，保留来源精度。明确的原借出及归还时分秒保留在原资料和记录中。
- 外部平台账号、支付商户、小程序身份及自动续费另行接入。

## 新批次导入

1. 使用[准备脚本](../../scripts/prepare_huiben_migration.py)准备数据并核对条码集合、借还记录、在借和库存。
2. 确认目标结构与来源映射，生成 SQL 预览；冲突标识或元数据先核实。
3. 使用独立临时数据库试导入，验证失败回滚、重复执行拦截和原有数据保留。
4. 通过适用完整验收，核对源系统自快照后新增业务并确定切换窗口。
5. 备份数据库、上传文件、配置和应用版本，校验备份；暂停必要写入后使用[导入脚本](../../scripts/apply_huiben_migration.py)执行。
6. 核对来源数量、身份及实体册关联、库存、金额、封面、权限和未涉及记录。重复来源批次不得再次导入。

## 已导入数据修正

使用有版本的独立修正脚本，按来源键、目标字段与预期原值限定影响范围。先输出只读预览及核对依据，再校验备份并事务执行；预期条件不符时中止。执行后核对指定字段及未涉及记录，记录重复执行结果和恢复办法。

已完成导入保留原批次和源快照，结构升级及业务补齐沿用既有身份，不重新整批导入。当前修正按[计划目录](../plans/README.md)推进。

### 不限次数的独立修正

入口为 [correct_huiben_unlimited_uses.py](../../scripts/correct_huiben_unlimited_uses.py)。默认只读预览，重新校验不可变来源文件、原批次哈希、会员来源键、原始档案、目标字段预期值与全表保护指纹；原始来源目录不得写入。未知或矛盾次数先核实，不以零值推断不限。

生产维护连接固定使用现有 `library_migrator`，密码仅从容器环境读取；应用账号继续只有 DML 权限。工具需核实临时表和触发器检查权限，发现相关触发器则拒绝执行，不依赖低权限账号不可见的空列表判断安全。

正式修正要求审核过的预览 SHA256、来源 SHA256、通过校验的完整备份及已停止的前后端。锁定事务内只持久修改指定会员的 `total_uses`，其他记录及字段核对通过才提交；预览之后发生非预期漂移则中止。重复执行不再改变数据，执行结果独立保存，不覆盖首次结果。

恢复使用首次成功执行结果生成独立反向预览，再经过同样审核、备份及预期值校验；仅恢复首次真正改变的字段，不用旧全库备份覆盖其后新业务。完整参数及用法见脚本 `--help`，真实预览、结果和备份留在受保护目录。
