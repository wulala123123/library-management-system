# 文档中心

固定项目入口为 [PROJECT](../PROJECT.md)、[PLAN](../PLAN.md)、[WORKFLOW](../WORKFLOW.md)和 [AGENTS](../AGENTS.md)。当前任务从 PLAN 恢复，领域内容按下表读取。

| 分类 | 入口 | 维护内容 |
| --- | --- | --- |
| 架构 | [架构说明](architecture/README.md) | 模块、数据流、事务和系统边界 |
| 领域规范 | [业务规范](specs/README.md) | 当前生效规则、字段含义和已知限制 |
| 开发 | [开发与验证](development/README.md) | 工具链、本地启动、检查与测试 |
| 运维 | [部署与数据维护](operations/README.md) | 发布、代理、数据库升级、导入和恢复 |
| 计划 | [计划目录](plans/README.md) | 活动计划、阶段任务和验收条件 |
| 发布 | [发布说明](releases/README.md) | 当前发布说明及历史来源索引 |
| 历史 | [历史档案](archive/README.md) | 已发生的检查、修复和现场验收 |
| 图片 | [界面参考](images/README.md) | 已跟踪的界面图片资源 |

新增文档只登记到所属目录索引，新增分类登记到本页。命名、拆分、归档及长度要求由 WORKFLOW 统一维护。
