# 批次2：无用代码与依赖清点

状态：待开始。初估1–2小时；目标、基线和共用护栏见[第二阶段总计划](README.md)，当前执行位置见[根目录PLAN](../../../PLAN.md)。

## 范围

检查前后端入口、静态导入、导出、路由、配置、动态调用、测试及打包引用，移除有充分依据的无用内容。当前前端9项直接运行依赖均有源码文本引用，依赖删减需进一步核实。

## 任务

- [ ] 为候选文件、符号和依赖记录引用证据，区分业务入口、框架动态使用、测试支撑和真正无引用内容。
- [ ] 核对路由懒加载、组件模板、Spring/MyBatis配置、反射及发布脚本，排除静态搜索的误判。
- [ ] 移除已证明无用的文件、导入、导出、变量或依赖；依赖确有调整时同步维护锁文件和构建配置。
- [ ] 对每组实际删除运行相关类型、编译或测试检查，记录移除清单与必要保留理由。

## 验证与完成条件

- 前端改动通过类型检查、构建和相关用例；后端改动通过编译及相关配置/入口检查，具体范围按实际删除影响确定。
- 取消后续开发不等于现有角色、读者接口或历史查询没有用途；无充分依据的内容保留并说明理由。
- 已发现候选均有可审查结论，实际删除有引用依据且必要检查通过，即结束本批；不强行达到删文件或删行数量。
