# 阶段 5 接通套餐规则与借还订单

阶段标识：MBA-05。依赖与总体完成标准见[项目路线](../../../../PROJECT.md)，执行游标见[当前工作](../../../../PLAN.md)。

- [ ] B50 建立一次办理多本书的借阅订单，关联独立借阅明细与实体册。管理员办理、自助借阅码核销和读者申请使用同一套规则。
- [ ] B51 借出前统一校验会员状态、权益有效期、单次本数、累计在借本数、次数、借阅期限及相应的语种和取书限制。
- [ ] B52 借阅天数根据权益提供固定期限或不限期；续借按对应权限、次数和天数处理。继续支持适用套餐的可调天数，并给出清晰的应还日期预览。
- [ ] B53 按阶段 0 确定的规则记录订单次数和实体册数，分别保存迁入期初值与本系统新增值。核销、出库及并发请求只能扣次一次。
- [ ] B54 自取流程支持待取、实际借出、取消和归还；按实际借出状态更新借阅明细。库存占用、释放、取消及重复操作都有明确处理。
- [ ] B55 支持按条码归还、单册归还、整单归还及部分归还；已核实的套装按规则办理。借还明细、实体册、汇总库存、流水和计次在相应事务中保持一致。
- [ ] B56 保留历史记录的原期限和状态。到期会员仍可归还；已存在的超限在借记录继续可归还，新限制按确定的生效方案应用于新增操作。
- [ ] B57 办理界面展示会员权益、当前在借、预计扣次、应还日期和限制原因。馆员例外操作采用独立权限，记录理由和操作人。

验收：会员到期、不同套餐、有限次数、不限次数、定期借阅、不限期借阅均有对应流程；并发借阅、重复核销、取消及部分归还不造成重复扣次或库存变化。历史不限期记录保持原含义。
