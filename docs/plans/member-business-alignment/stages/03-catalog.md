# 阶段 3 完善图书和逐册管理

阶段标识：MBA-03。依赖与总体完成标准见[项目路线](../../../../PROJECT.md)，执行游标见[当前工作](../../../../PLAN.md)。

- [ ] B30 明确两层记录：图书资料按书目管理；每本实体书按馆内条码管理。新增库存时登记对应实体册，默认新增数量建议为一册。
- [ ] B31 补齐条码登记、批量新增、查询、位置调整、停用与报损流程。条码唯一且保留前导零；已借出的册不能直接删除或改为可借。
- [ ] B32 采购入库、手工补录、报损和盘点统一维护实体册、汇总库存与变更流水。采购重复入库或请求重试不能重复增加册数。
- [ ] B33 图书表单与筛选增加适读年龄、装帧等有来源的属性。自定义书名作为展示名称保留，同时保留原书名。
- [ ] B34 建立套装与单册的关联，保留每册身份。仅有“套装中单本”标记而缺少明确归属时，进入待核实清单，核实后再建立关系。
- [ ] B35 建立分类与出版社资料，关联现有图书。年龄标签与主题分类分别管理；出版社同名先规范核对，名称相近的记录列为待确认。
- [ ] B36 统一书目位置、逐册位置和书架库位的使用方式，以逐册实际位置为准；原位置为空的实体册保留未分配。出版信息和简介另列补录任务，批量补录提供预览和来源。

验收：每笔新增实体库存均能查到对应册及条码；逐册状态与总库存一致；同一书目的多册可分别借还、放置和追溯。
