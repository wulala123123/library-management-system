# 阶段 2 统一会员档案和套餐

阶段标识：MBA-02。依赖与总体完成标准见[项目路线](../../../../PROJECT.md)，执行游标见[当前工作](../../../../PLAN.md)。

### 会员管理

- [ ] B20 将账号管理与会员档案关联。会员详情提供基础资料、家庭及宝宝资料、套餐权益、费用与押金、借阅历史几个区域；账号角色和登录状态保留独立含义。
- [ ] B21 新增和编辑会员使用相同的资料结构，支持卡号、套餐、服务起止日、会员备注及多名宝宝。卡号允许未设置，分配时检查重复。
- [ ] B22 将原资料中已确认的可用字段填入业务档案，记录来源和修订时间。原系统资料继续作为原始快照可查。
- [x] B23 用户管理和办理借阅支持按姓名、手机号、卡号和登录账号搜索。共享手机号返回多个会员供选择，继续使用独立会员身份。

### 套餐和权益

- [x] B24 建立可维护的套餐及版本，包含服务时长、单次限额、累计在借上限、次数类型、借阅期限、续借权限、语种和取书方式。
- [ ] B25 把会员当前权益与套餐版本关联，保留会员实际有效期、历史已用次数、单独调整及调整依据。迁入权益与新办权益通过相同接口读取。
- [ ] B26 在会员页面展示待生效、有效、到期等业务状态，以及已用次数、剩余次数或不限。此阶段先展示完整权益，借阅拦截在阶段 5 统一启用。
- [x] B27 明确权限：馆员可读取办理借还所需的会员资料；费用、押金和敏感家庭信息按业务权限开放；读者只访问自己的资料。

验收：迁入会员和新建会员均可查看、编辑同样的业务字段；修改姓名和联系方式不影响原借阅关联；更改套餐定义不覆盖现有会员的权益。

本地证据在私有 `logs/member-business-stage2/`：后端 v2 的 H2 35 项、MySQL 8.0 17 项及前端 23 项通过，类型检查构建通过。经理核对候选文件哈希、权限投影、跨账号/Profile 入口统一版本、卡号并发唯一、审计失败回滚、V4→V5 保值及来源只读；V1–V4 与线上基线逐字节一致。
