# 图书馆管理系统发布说明

基础能力包括验证码登录、账号状态与令牌撤销、图书借还、可选续借天数、采购、持久化上传、逐册条码、历史资料查询和增量迁入。用户与图书列表使用连续序号，数据库身份与关联保持原值。

当前会员套餐、收费、逐册管理和统计整合按 [PROJECT](../../PROJECT.md) 的阶段路线推进。已知限制见[业务规范](../specs/README.md)，阶段完成情况以相应任务及验收记录为准。

发布包包含应用产物、公开文档、部署和备份恢复脚本，排除真实业务快照、上传数据和凭据。只有通过目标提交完整 Verify 的产物用于生产；已有 Release 或标签不覆盖。

部署前阅读[部署与恢复](../operations/deployment.md)和[数据库迁移](../operations/database-migrations.md)。历史验收及产物来源见[档案](../archive/README.md)。
